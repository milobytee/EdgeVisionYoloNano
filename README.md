# EdgeVisionYoloNano
Contiene dos capacidades complementarias dentro del caso único de visión por  computadora: (a) un detector YOLO11-Nano con webcam USB físicamente conectada a la Orange Pi, de  acuerdo con el escenario escrito del PDF; y (b) un modelo multimodal Qwen3-VL-2B-Instruct que  interpreta fotografías subidas desde el navegador o capturadas desde la cámara
