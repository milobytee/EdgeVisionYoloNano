02 · Inteligencia artificial

Dos formas de comprender imágenes

Detección

YOLO11-Nano + ONNX Runtime

La cámara USB alimenta la Orange Pi. YOLO detecta clases y posiciones, añade recuadros y transmite video hacia el portal.

Ejemplo observado: aproximadamente 1.26 FPS en una prueba del laboratorio.

Interpretación multimodal

Qwen3-VL-2B-Instruct

Un modelo visual y lingüístico que recibe una fotografía y una pregunta en español para generar una descripción contextual.

Cuantización Q4 y componente de proyección visual mmproj.

RPC permite distribuir cálculos, pero no garantiza mayor velocidad. El rendimiento depende del modelo, los datos transferidos y la conexión entre nodos.
